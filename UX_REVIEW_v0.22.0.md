# PinBlocks naming / UX review

## Name
Keep **PinBlocks**. It is short, pinball-specific, memorable, and describes the block-building mental model. Present it as **PinBlocks by Houseball Amusements** rather than renaming the tool.

## Teaching approach
The numbered path remains the lesson: Set Up → Components → Rules → Test → Export. Reference is deliberately outside the numbered steps because reading documentation should not be a prerequisite.

## Reference strategy
Link to a few authoritative MPF pages instead of copying the MPF manual into PinBlocks. v0.22 includes Quickstart, Config Reference, Shots, and Config Players.

## Complex modes
A complex imported MPF mode should be truthful before it is pretty. Conditional events are now summarized and collapsed in Test, while their raw MPF expression remains available.
